# Modélisation de bases de données :

Exercices réalisés avec le MCD, MLD puis MPD + le MCD et le MLD pour l'atelier

# Contenu :

1. Exercice potions : MCD (association N,N entre potion et ingrédient), et MLD (table "ingredient_pour_potion") et MPD (création des 3 tables avec clés primaires et étrangères).
2. Atelier SPA, MCD avec les entités Espèce, Race, Animal, Adoptant et Refuge, leurs relations et les cardinalités
3. Atelier SPA, MLD avec une table "Adoption" (id, date_heure, id_animal, id_adoptant) qui enregistre chaque adoption avec sa date et son heure.

# Technologies utilisées :

- MCD, MLD, MPD
- Excalidraw (schémas)

# Problèmes :

J'avais fait pas mal d'erreurs avant le live de Loïc et aussi des problèmes avec les cardinalités et les relations en général sur certains points
